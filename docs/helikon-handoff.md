# Helikon handoff

Subsequently published with the owner's explicit authorization. The
[public delivery record](helikon-publication.md) retains canonical bytes,
actual browser/export/offline results and the remote CI boundary. The local
handoff below records the earlier review and its original publication boundary.

Pyknon now has an operable helikon room: build the square and its four strings,
hear seven interval relations, alter the common bridge, then fit three
fourth-span target divisions by moving the two inner strings. The two end
notes fix a straight bridge; transposition preserves the inner errors until
the strings themselves move. Six Greek/Latin/English selections and eight
whole source pages keep the historical argument inspectable.

The first board follows Ptolemy’s _Harmonics_ II.2. The smaller retuning exercise
is a modern analogy of the movable-string principle, using the Archytas
numbers reported in I.13. It is not a physical reconstruction. Editable JSON,
exact CSV, SVG, WAV and a script-free illustrated reading retain actual learner
settings. The example PDF has 21 pages.

## Build and operate

```sh
npm ci
npm run dev
```

Choose **Helikon**, or open `/pyknon/helikon.html` on the printed development
address. The normal development and preview port is 4329.

```sh
npm run check
npm run verify:helikon
npm run build
npm run preview
```

`npm run build` creates `dist/`. The complete static output is 115 files,
31,262,887 bytes, including its service worker. It covers all ten rooms.
The final production edition has 114 precached files and its separate worker.
