# Translating a Greek musical sign

## Audience and one job

A fluent English reader can already recognize a Greek letter and still read a
musical sign in the wrong alphabet. This desk teaches one concrete act: preserve
notes while translating a short newly composed exercise between Alypius’s vocal
and instrumental sign pairs. The original table remains within reach.

## Visual plan and critique

Pyknon already uses a violet listening desk. Keep that identity: ink #25223b,
vocal violet #51419b, instrumental orange #ad4a19, pale violet #f0edf9,
paper #ffffff and muted text #626070. Use self-hosted IBM Plex Sans for the
instructions and controls, Noto Serif for Greek phrases, and explicit SVG paths
for the selected musical signs. Those paths are new teaching diagrams checked
against the 1895 print, not extracted font glyphs or manuscript facsimiles.

The signature is a paired musical strip. Each column shares a note, but its two
signs differ. A large Z switches between the two reading alphabets; the same
shape moves to a different named note. It is evidence for the lesson, not a logo.

```text
SAME SHAPE                        TWO READING ALPHABETS
+-------------------+   +------------------------------+
|         Z         |   | vocal: paramese               |
| choose an alphabet|   | instrumental: nete synemmenon |
+-------------------+   +------------------------------+

TRANSLATE THE EXERCISE             CHECK THE PRINTED ROW
+-------------------+   +------------------------------+
| vocal       I Z U I|  | whole page / selected row      |
| instrument  ? ? ? ?|  | Greek description / new English|
| choose a slot     |   | paired signs                  |
+-------------------+   +------------------------------+
```

A generic quiz-card layout would hide the useful correspondence. Reject scores,
random questions, streaks and a piano keyboard. Keep the complete paired lookup
visible while the learner writes the translated line; its ordered rows and the
selected source band explain each choice. Wrong choices stay in the line until
the learner replaces them. Keep “same note” distinct from “same table function”.

## Scope and truthful sound

Use a selected diatonic span of Alypius’s Lydian table, Jan 1895 pp368–369.
The Hypolydian comparison on p370 shows that a shared sign can change function
between tables. Neither the ethnic labels nor a modern Hz reference establishes
an ancient regional sound. Keep tuning, equal note durations and synthetic sine
tones explicitly instructional. Sound is optional; the written comparison must
explain the result on its own.

Whole source pages include the editorial apparatus. Greek shape descriptions
teach vocabulary such as sideways, upright and reversed through actual sign
transformations. New English glosses do not invent an ancient Latin original.
The short practice line is newly composed from table entries, not a lost melody.

## Retained work

pages, fonts and licenses. A URL is copied only on explicit action. Validate the
